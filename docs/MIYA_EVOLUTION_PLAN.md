# План развития Мии: от алгоритма к AI-агенту

**СОЗДАНО 2026-10-30**

## Текущее состояние (2026-10-30):
- ✅ Inline MIYA в Go-коде (без внешних скриптов)
- ✅ RSI(14), SMA20/50, тренд, ликвидность
- ✅ Рекомендации топ-5 с action (buy/sell/hold) и score (0-100)
- ✅ Мия-стратег: режимы (aggressive/normal/conservative/pause)
- ✅ Мухля применяет множители Мии (TP/SL/size)
- ✅ Фьючерсы в аналитике (tickers=17)
- ⚠️ Мухля пока не слушает рекомендации (AKPP conf=0.85 > TATN conf+bonus)

## Уровень 1: Умный алгоритм (1-2 недели)

### 1.1 Счётчик точности рекомендаций
- Таблица `miya_recommendations` в Postgres (уже создана)
- Через N часов проверять цену → win/loss/pending
- Считать % точности по тикерам, action, score
- **Скрипт:** `scripts/miya_recommendation_accuracy.py` (нужно доработать)

### 1.2 Адаптивные веса индикаторов
- Если RSI точность < 50% → снизить вес в score
- Если тренд точность > 70% → увеличить вес
- Формула: `weight_i = base_weight_i * accuracy_i / avg_accuracy`

### 1.3 Дополнительные индикаторы
- MACD (уже есть в `indicators.go`)
- Bollinger Bands
- ATR (волатильность) — для адаптивного SL/TP
- Объёмы (сравнение с средним)

### 1.4 Секторный фильтр
- Не покупать >30% из одного сектора
- Группировка: нефть/газ, банки, металлы, телеком

## Уровень 2: ML-аналитик (2-4 недели)

### 2.1 Бэктест в trading-lab
- Проверить текущую стратегию на истории
- Оптимизировать пороги (RSI, score, gate)
- `trading-lab/validate_policy.py` — уже есть

### 2.2 Модель предсказания
- Logistic regression / Random Forest
- Признаки: RSI, SMA, trend, volume, sector
- Цель: предсказать рост/падение через N часов
- Python → JSON → Go (через `AGENT_POLICY_PATH`)

### 2.3 Корреляции
- Анализ связей между тикерами
- Если SBER растёт → вероятно VTBR тоже
- Диверсификация портфеля

## Уровень 3: AI-агент с LLM (1-2 месяца)

### 3.1 LLM для макро-анализа
- Анализ новостей (NLP)
- Ключевые ставки ЦБ
- Геополитические события
- API: DashScope / OpenAI

### 3.2 Дневник и объяснения
- Автоматический анализ ошибок
- "Почему я рекомендую TATN" — текстовое объяснение
- Еженедельный отчёт по PnL

### 3.3 Стратегическое управление
- Сама выбирает режим (не по фиксированным правилам)
- Адаптация к волатильности рынка
- Управление портфелем (ребалансировка)

## Приоритеты

1. **Счётчик точности** — без него нельзя улучшить
2. **Усиление влияния Мии на Мухлю** — gate reduction + conf bonus
3. **MACD + ATR** — больше данных для анализа
4. **ML-модель** — после стабилизации алгоритма

**Why:** Мия должна эволюционировать из дублирующего аналитика в полноценного стратега, который реально помогает Мухле зарабатывать.
**How to apply:** Двигаться пошагово. Каждый уровень — после подтверждения работоспособности предыдущего.
